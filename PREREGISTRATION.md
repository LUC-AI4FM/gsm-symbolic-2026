# Pre-registration

Committed on 2026-11-06, before any GSM-Symbolic, P1, P2 or NoOp result was scored. Any later change to
this file is visible in git history; analyses not listed here are reported as exploratory.

  completion (paper: 74.0). A first attempt through the chat API with a `Q:` stop sequence scored 31/100

## Hypothesis H1 (from Eric Spencer)

> 2026 models will do much better on GSM-Symbolic, P1, P2 and NoOp than the paper's models.

### Measures

For model *m* and variant *V* in {Symbolic, P1, P2, NoOp}:

- `acc(m, V)`: mean accuracy over instance sets (each set = one instance of every template).
- `drop(m, V) = acc(m, GSM8K-100) - acc(m, V)`, in percentage points, where GSM8K-100 is the 100
  original GSM8K test questions the templates were built from (paper Tab. 1, column "GSM8K (100)").
- 95% confidence intervals by paired bootstrap over templates (10,000 resamples; for the GSM8K-100
  baseline the template's original question is paired with its instances).

Reference values from the paper (Tab. 1), best model o1-preview: GSM8K-100 96.0, Symbolic 92.7, P1 95.4,
P2 94.0, NoOp 77.4 (drops 3.3, 0.6, 2.0, 18.6). GPT-4o: 95.0, 94.9, 93.9, 88.0, 63.1.

### Thresholds, fixed now

A 2026 model **meets H1** when all four hold:

| Variant | Drop at most | Reason |
|---|---|---|
| Symbolic | 2 points | the paper's strongest models drop 0 to 3 |
| P1 | 5 points | |
| P2 | 10 points | GPT-4o dropped 7.0 and o1-mini 3.9 |
| NoOp | 9.3 points | half of o1-preview's 18.6 |

- **H1 supported**: at least two thirds of the 2026 models we run on all four variants meet H1, and the
  median 2026 NoOp drop is below 9.3 points.
- **H1 refuted**: the median 2026 NoOp drop is 17.5 points or more (no better than o1-preview), or the
  median 2026 Symbolic drop exceeds 5 points with a CI that excludes 0.
- **Partly supported** otherwise. We report each variant separately whatever the verdict, including any
  variant where 2026 models still drop.

## Hypothesis H2: variance across instance sets is sampling noise

For each model and variant, compare the standard deviation of accuracy across instance sets with the
binomial expectation `sqrt(p(1-p)/n)` (n = templates per set). H2 holds for a cell when a parametric
bootstrap of 10,000 binomial replicate sets puts the observed SD below the 97.5th percentile.
We report the share of cells where H2 holds, and the paper's "variance" claim is judged against it.

## Hypothesis H3: NoOp drops come partly from ambiguous distractors

Our NoOp sentences are generated by one model and judged by two others ("does the answer stay
unchanged?"). We report NoOp accuracy on all items and on items both judges call UNCHANGED.
H3 holds when the drop on the unanimous subset is at least 30% smaller than on all items, for the
median model.

## Reproduction check

Llama-3-8B-Instruct (the paper evaluated it) through raw completion on Bedrock. Reproduced if our
Symbolic, P1 and P2 means fall within 2 paper standard deviations of Tab. 1 (74.6 ± 2.94, 53.8 ± 4.54,
28.3 ± 4.37). Our NoOp is a reconstruction, so the NoOp comparison is descriptive only.

## Fixed protocol

- Prompt: the README template, the 8 common GSM8K CoT exemplars (lm-evaluation-harness commit c0745fec).
- Decoding: temperature 0 where the API accepts it; models that reject it (Kimi K3) use defaults and are
  flagged. Reasoning models keep their default reasoning setting.
- Extraction: the paper's rule (truncate at `\nQ:`, drop commas, last number, float compare).
  The "final answer is" rule is reported as a sensitivity check only.
- Claude models run only as Claude Code subagents (batched prompts, no tools, default sampling) and are
  reported in a separate table; they are not counted in the H1 verdict's model pool unless they run
  every variant, and their comparability limits are stated.
- Pilot (few instance sets) results are exploratory; the verdict uses the largest set count each model
  completes, stated per model.
